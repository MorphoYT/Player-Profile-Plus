# 🤝 Contributing to Player Profile Plus

Thanks for your interest in contributing to **Player Profile Plus**! Every useful suggestion and improvement is appreciated.

## 💡 Suggest an Idea

Have an idea for a new feature or improvement?

- Open an issue in the GitHub repository.
- Describe your idea clearly.
- Explain how it could improve the player profile experience.

## 🐛 Report a Bug

If you find a bug:

- Open a GitHub issue.
- Explain what happened and what you expected to happen.
- Include your Geometry Dash version, Geode version, and relevant details.
- Include steps to reproduce the issue when possible.

Please avoid posting private information in issues.

## 💻 Contribute Code

If you'd like to contribute code:

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Submit a pull request explaining what you changed and why.

Please keep changes focused and follow the existing code style.

## ✅ Before Submitting

- Check that your changes match the project's goals.
- Test your changes when possible.
- Update documentation if needed.
- Be respectful and constructive toward other contributors.
